# Build a Large Language Model (From Scratch)

The code re-implement in Tensorflow for Build a Large Language Model (From Scratch)<br>
Textbook: [ISBN 978-1633437166](https://www.manning.com/books/build-a-large-language-model-from-scratch)<br>
The book will give [official torch code](https://github.com/rasbt/LLMs-from-scratch) implemented by author
And the Project will implement the tensorflow alternative code.

## Requirement & Environment

Python 3.12<br>
TensorFlow >= 2.16 for PyDataset | keras 3.3.0 (detail in https://github.com/keras-team/keras/issues/20098#issuecomment-2276446043)<br>

## Dataset

If you want to get the dataset, please refer the repo [the-verdict](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch02/01_main-chapter-code/the-verdict.txt).
